# Development of Emotions — Interactive B.Sc. Nursing Presentation

An interactive two-page presentation website prepared by **Aviraj A. Veer** for **KVV Karad · B.Sc. Nursing**.

## Topics

- **Topic I — Development of Emotions** (`index.html`)
  - Developmental stage explorer
  - Age growth map
  - Emotion lab
  - Nursing clinical scenarios
  - Theory lenses and instant-feedback knowledge check

- **Topic II — Emotional Development Throughout Life** (`topic-ii.html`)
  - Lifespan emotional-development explorer
  - Age-wise animated faces and orbiting themes
  - Influences on emotional development
  - Nursing communication guide across the lifespan

## Run locally

```bash
npm start
```

Then visit [http://localhost:3000](http://localhost:3000).

## Project structure

```text
├── index.html       # Topic I
├── topic-ii.html    # Topic II
├── styles.css       # Shared visual design and responsive styles
├── app.js           # Topic I interactivity
├── topic-ii.js      # Topic II interactivity
├── server.js         # Local Node.js static server and API
└── package.json
```

> Runtime reflection and quiz-result files are intentionally excluded from Git via `.gitignore`.
